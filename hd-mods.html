HD Mods

Willybach's and Badger's HD graphics set — what each part does, which parts are optional, and how to install it by hand.

What this is

A set of mods from Nexus that replace Valheim's textures, terrain, shading, sky, portals and map with high-resolution versions while keeping the vanilla look. Two authors make them and they are designed to be used together: Willybach paints the textures, Badger writes the plugins that load them and the shaders that render them.

Everything here is client-side and purely visual. Nothing goes on the server, nobody else has to install it, and you can play on Bahnsheim with or without it. Requires about 30 GB of disk space and adds at least a minute to your startup time.

The parts

Each part is a download from Nexus that unpacks to a plugin DLL and a data folder, or just a data folder that feeds another part's DLL. The Core parts are the set; the rest are optional, and the Recommended ones are what we run.

Installing it in Gale

These mods are only on Nexus, not Thunderstore or Hexium, so Gale cannot install or update them. You download them yourself and unpack them into a profile's plugins folder, where they load alongside everything Gale manages. Every archive is laid out so that its root is the plugins folder: the DLL and its data folder sit at the top level, ready to drop in.

  1. Give them their own profile. In Gale, duplicate the profile you play with (Default SD) and call the copy something like Default HD. Loading is noticeably slower with the HD set, so keeping it in a separate profile lets you flip back for a quick session. Duplicate inside Gale, not by copying the folder: Gale keeps its profile list in a database, and a folder it did not create is not a profile.
  2. Download from Nexus. You need a Nexus account; the files are manual downloads. The HIGHER texture pack is about 5.7 GB as a 7z archive. Have 7-Zip installed, since the packs come as .7z and .rar, not .zip.
  3. Unpack each archive straight into the profile's plugins folder. 
    %APPDATA%\com.kesomannen.gale\valheim\profiles\Default HD\BepInEx\plugins

    Do not create a sub-folder per mod. The DLLs and data folders must sit directly in plugins, next to Gale's own Author-Mod folders.

  4. Mind the order for the two overwrites. Install Badger's HD Terrain before Willybach's HD Terrain Tiles, and say yes when the tiles ask to overwrite files in HDTerrainData. Then put Badger's hdterrain and TerrainConfig.json back from his archive: the tiles archive carries older copies of both and overwrites them, but only the tiles are meant to change. Install Badger's Valheim Skies before any HD Skies pack, so the skybox folders land inside BadgersValheimSkies\Skybox.
  5. Check the folder. With everything installed, the plugins folder should contain these, side by side:
    plugins\ ├─ HDValheimTextures.dll ├─ HDValheimTexturesData\ ├─ ValheimHDTerrain.dll ├─ HDTerrainData\ ├─ BadgersShadingOverhaul.dll ├─ BadgersValheimSkies.dll ├─ BadgersValheimSkies\ Environment\ and Skybox\ inside ├─ HDPortalFX.dll ├─ HDPortalFXData\ └─ PanocHDMap\ PanocHDMapEnable.dll and its data inside
  6. Launch from the new profile and wait at the menu. The texture pack reads its 2,987 replacement textures from disk every launch, not just the first, and shows "Loading HD Valheim Textures, Please wait..." while it does. On a fast NVMe drive that is about 50 seconds added before the main menu; a hard drive will take longer. Each mod writes its config into BepInEx\config on the first run.
Updating is the same as installing: download the new archive and unpack it over the old files. Gale's update check will never mention these mods, so look at the Nexus pages now and then. Removing the set is deleting the DLLs and data folders listed above from the profile's plugins folder, or just switching Gale back to your other profile.

Settings worth knowing

All of these live in the profile's BepInEx\config folder after the first run.

  • Which sky you get is Current skybox under [SkyBox] in Badgers.ValheimSkies.cfg. It names a folder under BadgersValheimSkies\Skybox, so after installing the Aurora pack set it to the Aurora folder's name. The same file hides or shows Yggdrasil and sets overhead cloud, distant cloud and ground mist density.
  • Shading Overhaul toggles in game with Page Down (changeable in BadgersShadingOverhaul.cfg), which is the quickest way to see what it does. The same file has specular intensity, ambient light, color temperature and saturation sliders.
  • HD Terrain has GrassDrawDistance and GrassAmountModifier in ValheimHDTerrain.cfg if the ground costs too many frames, a water caustics switch, and F6 / F8 to hot-reload textures and the shader. Those two keys are live in game, so if something else uses F6 or F8, rebind them here.
  • HD Portals is configured in HDPortalFXData\HDPortalFX.json, not a .cfg. The README next to it explains the seven layers; the original is kept as HDPortalFX - ORIGINAL.json if you want to go back. The two builds use different layer formats: in the AI Images version a layer's type set to Invisible hides it, in the video version the word is Disabled.

  • Deep North is the thing to watch for. Every part of the set predates the biome except the two 1.0 fixes, so Deep North ground is the Mountain's tiles, the portal stills and textures for its new objects are whatever vanilla has, and HD Terrain's proper split of the biome is still alpha. Check Badger's HD Terrain and Willybach's HD Valheim on Nexus before heading there.
  • Shading Overhaul 0.6.0 is the compatibility fix for Valheim 1.0 and the Deep North. 0.5.0 and earlier predate 1.0.
  • Valheim Skies 0.15.0 folds the old "for Willybach's Aurora" variant into the one download and bundles 24 skyboxes of its own. 0.14.1 was the Aurora-only variant. Willybach's Aurora and Milky Way packs are extra skybox folders for it, not replacements.
  • HD Terrain 2.1.0 does not work on Valheim 1.0. It was built before 1.0 changed the console-command constructor, so its console patch throws on every launch. That aborts the game's console and chat setup: the console window stays open at the top left showing placeholder lines of "Some text." and "asdasdasdasd", F5 does nothing, and in-game chat never registers. The 2.2.0 alpha is the only build made for 1.0. Badger calls it alpha because its Deep North ground, split from the Mountain's, still has visual bugs.

If you installed the old way

Before version 2.0, Willybach's pack was installed by overwriting files inside the game folder itself: a new globalgamemanagers.assets, a few hundred bundles under valheim_Data\StreamingAssets, and a BepInEx folder with aedenthorn's CustomGraphicsSettings plugin. Our older notes still describe that method. It is obsolete.

Valheim's 1.0 patches replaced those game files with vanilla ones, so nothing from an old install is still in effect. What may be left behind is a BepInEx folder inside the game directory holding only CustomGraphicsSettings.dll and a stray config. The game does not load it, since the mod manager starts the game with its own profile folder, and deleting it is safe but not required. Version 2.0 and everything else on this page goes in the profile's plugins folder, never the game folder.
